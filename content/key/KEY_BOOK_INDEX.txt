KEY / META-JAVA — INDEX OF THE KeY BOOK
=======================================

Source: https://www.key-project.org/thebook2/
Book: Deductive Software Verification — The KeY Book (LNCS 10001, 2016)
DOI: https://doi.org/10.1007/978-3-319-49812-6
Table of contents PDF:
https://www.key-project.org/wp-content/uploads/2018/10/KeYBook_TableOfContents.pdf

The book describes KeY 2.6.1. Page numbers below are the printed book pages
from the official table of contents. The primary syntax reference for the
“meta-Java” constructs (method frames, schema variables, schematic blocks,
meta-constructs, etc.) is Chapter 21, §21.2.5 “Schematic Java Syntax”,
pp. 650–654.

NOT COVERED BY THE BOOK
-----------------------

- The old KeY `merge_point ( expr );` form. No occurrence was found in the
  available chapter preprints (Chapters 3, 4, 9, 15); the JMLtk JML merge point
  is a JMLtk/KeY extension.
- AST-only or currently unparsed JMLtk nodes: `KeyMarkerStatement`,
  `KeyEscapeExpression`, `LogicalType`, `ArrayLengthValueDeclaration`,
  `KeyCatchBranch`. These have no book section; they are AST/resolver-level or
  unparsed.
- JML constructs are covered by Chapter 7 (pp. 189–238) and Appendix A
  (pp. 609–618), but they are intentionally outside this meta-Java index.

HOW TO USE THIS INDEX
---------------------

1. For the syntax of a JMLtk KeY construct, start with Chapter 21 §21.2.5,
   pp. 650–654.
2. For its semantics, follow the chapter/section in the middle column.
3. For schema-variable kinds and taclets, use Chapter 4 §4.3.2, pp. 128–134.
4. For Java Card transaction behavior, use Chapter 10 §10.3–10.4,
   pp. 353–360.
5. For program-transformation meta-constructs, use Chapter 14 §14.1–14.2,
   pp. 468–485.
